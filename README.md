# Панель путешественника
Тема: Интерактивная панель виджетов для путешественника
Технологии: HTML, CSS, Vanilla JS, ES6 классы, модули, localStorage

## Запуск
Скачайте все файлы в одну папку, откройте index.html в браузере.
Для публикации используется GitHub Pages.

## Источники API
1. Open-Meteo — погода: https://open-meteo.com/ (без ключа)
2. Frankfurter — курсы валют: https://www.frankfurter.app/ (без ключа)

## Нейросеть и промпты
Код сгенерирован с помощью Doubao.
Полезные промпты:
1. Создай базовый класс Widget на JS для виджета с методами render, toggleCollapse, getState для сохранения в localStorage
2. Напиши виджет погоды на Open-Meteo с состояниями загрузки, ошибки и кнопкой повтора, без ключа
3. Сделай панель управления виджетами: добавление, удаление, восстановление после перезагрузки страницы

## Функционал
- Добавить, свернуть, удалить виджет
- Виджет дел: добавить задачу, отметить выполнено, удалить
- Погода и валюты: загрузка, ошибка, повтор запроса
- Состояние сохраняется в localStorage
- Адаптивный дизайн под телефон и ПК
- Ошибка одного виджета не ломает остальные
